# 💰 Gestore Spese Personali

Una moderna applicazione web per il tracciamento delle spese quotidiane, sviluppata con l'assistenza dell'Intelligenza Artificiale (Google Antigravity).

## ✨ Funzionalità
- ⚡ **Scorciatoie veloci**: inserimento con un clic per spese frequenti (pane, pasta, frutta, caffè, trasporti).
- 🔍 **Filtro per categoria**: visualizzazione filtrata con ricalcolo immediato del totale per categoria.
- 💾 **Salvataggio automatico**: i dati rimangono memorizzati nel browser del dispositivo (localStorage).
- 📱 **Mobile-First**: ottimizzata per smartphone, utilizzabile come Web App.
